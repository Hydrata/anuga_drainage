# Security Policy

`Hydrata/anuga_drainage` is a fork of [`stoiver/anuga_drainage`](https://github.com/stoiver/anuga_drainage). Where to report depends on whose code is affected.

## Vulnerabilities in Hydrata's patches

Anything that only exists in this fork (Hydrata's commits ahead of upstream) goes to Hydrata, privately:

- GitHub: use **Security > Report a vulnerability** on this repository, or
- email [david.kennewell@hydrata.com](mailto:david.kennewell@hydrata.com).

Please do not open a public issue or pull request for a suspected vulnerability.

## Vulnerabilities in upstream code

If the flaw is in code that also exists in `stoiver/anuga_drainage` (check against the upstream branch first), report it to upstream. Use the upstream repository's Security tab (Report a vulnerability) if it is enabled, otherwise contact its maintainer through the upstream issue tracker without including exploit detail. We will pull the fix into this fork once upstream releases it.

## Supported versions

Only the current trunk of this fork receives fixes from Hydrata.
